# 🎮 Mini Quiz App

A modern and interactive quiz web application built with **Vue 3 + TypeScript**.  
This project demonstrates frontend logic, state management, UX design, and progressive difficulty system.

## ✨ Features
- Multiple choice quiz
- 30 curated questions
- Difficulty levels (Easy / Medium / Hard)
- Difficulty-based questions & timer
- Progression system (unlock difficulty)
- Countdown timer per question
- Progress bar
- Answer highlight (correct / wrong)
- Review answers after quiz
- Best score & progress saved in localStorage
- Modern UI with gradient & glassmorphism

## 🛠 Tech Stack
- Vue 3 (Composition API)
- TypeScript
- Vite
- CSS (custom design system)

## 🎯 Difficulty Rules
- **Easy**: always unlocked
- **Medium**: unlocked if Easy accuracy ≥ 70%
- **Hard**: unlocked if Medium accuracy ≥ 70%

## 🚀 Getting Started

### 1. Clone repository
```bash
git clone https://github.com/USERNAME/mini-quiz-app.git
cd mini-quiz-app
2. Install dependencies
npm install
3. Run development server
npm run dev
Open browser at:
http://localhost:5173
```
